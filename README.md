# 📄 Resume Analyzer with AI 🤖

A Streamlit web app that analyzes resumes and matches them with job descriptions.

## 🚀 Features
- Extracts text from PDF & DOCX resumes
- Uses NLP to extract skills
- Compares resume with job description using AI
- Provides a match score

## 📌 Setup
```bash
pip install -r requirements.txt
#You may need to add: python -m spacy download en_core_web_sm
streamlit run app.py
